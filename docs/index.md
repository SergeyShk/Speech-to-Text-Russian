# stt-ru

![stt-ru](img/logo.jpg)

**stt-ru** - инструмент распознавания русской речи: библиотека Python, команда `stt-ru`, веб-сервис и Docker-образ. Речь распознает модель [GigaAM-v3](https://github.com/salute-developers/GigaAM) через [onnx-asr](https://github.com/istupakov/onnx-asr): текст получается с пунктуацией и числами, стереозапись разбирается по каналам, результат сохраняется в субтитры и таблицы.

!!! note "Пакет в разработке"
    Первый выпуск пакета - 0.3.0. До него рабочая версия на Kaldi описана в [README](https://github.com/SergeyShk/Speech-to-Text-Russian#readme).
